BUILT WITH PIXELS & NEON

本站的赛博朋克效果是怎么做出来的？全部纯前端，零框架，零依赖。

▚▞

像素字体

使用 Press Start 2P 与 VT323，16-bit 红白机时代字体，配合 image-rendering:pixelated 保留锯齿质感。

▣

数字雨

Canvas 逐帧渲染，字符列沿 Y 轴下落，用 shadowBlur 制造霓虹光晕，透明度叠加形成拖尾。

◤

CRT 扫描线

CSS repeating-linear-gradient 叠加 1px 黑线 + 径向暗角 + 扫光条动画，模拟老式显示器。

≋

Glitch 故障

伪元素复制文字，用 clip-path 切片 + 错位 translate + steps() 跳跃动画模拟信号故障。

▦

电路纹理

多层 linear-gradient 叠加出 16px/80px 双层网格，再叠加霓虹色细线，像 PCB 电路板。

◈

像素裁剪

clip-path 多边形切角 + 切角边框，让按钮和卡片呈现硬朗的 16-bit 切割边缘。

// 核心配方：暗底 + 霓虹发光 + 像素节奏
body {
  background: #000005;
  color: #e8e8ff;
}
.glow {
  color: #ff2fd6;
  text-shadow: 0 0 12px #ff2fd6, 0 0 40px rgba(255,47,214,.5);
  animation: blink 1s steps(2) infinite;
}
// steps() 是像素感的关键：不做平滑插值
